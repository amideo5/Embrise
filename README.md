# Embrise Solutions — Website

A React 19 + Vite website for Embrise Solutions. The site uses React Router (HashRouter), Tailwind utilities, Framer Motion, React Slick and Formspree.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Site structure

- `src/pages/` — homepage, service detail pages and editorial articles.
- `src/components/` — shared navigation, footer, homepage sections and service process layouts.
- `src/styles/site.css` — shared visual system and responsive layouts.
- `src/assets/` — brand assets and service illustrations.

## Visual system

The refreshed interface uses a consistent warm-neutral canvas, deep wine brand colour, editorial typography, fine dividers, restrained motion and responsive layouts. Homepage sections and all service/article pages share the same visual language. Existing service routes, article routes and the Formspree contact form are retained.
